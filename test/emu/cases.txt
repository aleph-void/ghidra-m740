# Hand-computed p-code cases for the MELPS 740 module (test/emu-test.sh).
# Code is written at ram:1000; S starts at FF, all flags at 0, registers at 0.
# "set ram:<addr>[/n] <value>" little-endian n-byte memory; "expect" lists results.
# Stack: zero page, push = M(S) <- byte, S <- S-1; JSR pushes PCH then PCL of the last byte.
# Results below were worked out from the Series 740 User's Manual (1989), not from the module.
